# Keys Media Studio — Strip 01: "They Buy the Feeling"

**Format:** 8-panel carousel strip (4:5, 1080×1350). Works as a vertical Reel with the same beats (~20s).
**Audience:** Luxury listing agents, Florida Keys.
**Goal:** Waitlist sign-ups for partnership.
**Core idea:** Every agent says "buyers buy with emotion." Few can actually *manufacture* it. Emotion = story. Story is a craft. That's us.

## Notes on the brief (edits I made and why)

- **Cut "we worked to be the best."** Self-praise reads as filler at the luxury tier. The pitch is stronger when the agent is the hero and Keys Media Studio is the guide.
- **"Most desired agent in the entire Florida Keys" → "the agent people ask for by name."** Same promise, more concrete, less claim-y.
- **Added scarcity ("limited agents per market").** Only keep this if it's true — i.e., if you actually cap partners by town (Key West / Islamorada / Marathon, etc.). If not, drop it.
- **Panel 4 is the whole strip.** If you only get one shot right, it's that one. Needs a real property and real golden-hour footage — stock will kill it.
